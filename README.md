## Funcionalidades
Aplicação em Java para escrever, guardar, listar e buscar cartas pessoais, integrada ao banco de dados relacional MySQL via JDBC.
- **Cadastro de cartas:** registro de cartas pessoais (com local e visibilidade) e cartas musicais (com música trilha e artista).
- **Listagem de cartas:** visualização das cartas salvas no banco de dados.
- **Busca:** consulta de cartas por palavra-chave ou destinatário.
- **Validação de dados:** tratamento de campos obrigatórios e regras de preenchimento com exceção personalizada.
